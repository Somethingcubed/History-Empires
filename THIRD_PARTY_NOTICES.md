## Cliopatria expanded time-slice boundaries

`data/cliopatria-expanded-boundaries.geojson` is a compact derived subset of **Cliopatria**, an open geospatial dataset of worldwide polities from 3400 BCE to 2024 CE by the Seshat Global History Databank project.

- Source: https://github.com/Seshat-Global-History-Databank/cliopatria
- Dataset reference: https://zenodo.org/records/13363121
- License: Creative Commons Attribution 4.0 International (CC BY 4.0) — local copy at `data/cliopatria-CC-BY-4.0-LICENSE.md`
- Transformation: matched 147 `empires.json` rows to Cliopatria, retained multiple overlapping time-slices per empire (capped for browser performance), rounded coordinates to 5 decimals, and retained source year ranges and area metadata.

Cliopatria's authors note that historical borders are interpretive and should be evaluated for the intended use.

## Ancient civilizations markers (optional map overlay)

`data/kimi-ancient-civilizations.geojson` is a bundled copy of the **Ancient Civilizations Spatiotemporal Dataset** assembled in the repository folder `Kimi_Agent_古文明GIS架构师及数据/` (research notes, schema, and CSV live there).

- **License:** Creative Commons Attribution-ShareAlike 4.0 International (**CC BY-SA 4.0**) — see section 8 of `Kimi_Agent_古文明GIS架构师及数据/data_dictionary.md` and https://creativecommons.org/licenses/by-sa/4.0/
- **Use:** optional map markers filtered by the map year slider; interpretive chronology and archaeology-focused metadata — not a substitute for scholarly GIS sources. The same file is **matched heuristically** to timeline empires (see `js/kimi-enrichment.js`) to append an optional “More context” section in the slide-out detail panel when names and dates overlap; mismatches are possible — use `data/kimi-empire-overrides.json` to pin `empire id → civilization_id` when needed.

If you redistribute this site or derivative datasets built from this GeoJSON, comply with **CC BY-SA 4.0** (attribution + ShareAlike for adaptations).

## Continuous visual boundary layer

`data/empire-boundaries-continuous.geojson` is generated by `tools/build-continuous-boundaries.py` for the world map's casual historical-atlas view. It combines:

- Timelory sampled-year GeoJSON features from `https://api.timelory.com/api/regions/postgis?year=...`, used as real coordinate snapshots for visual continuity where names match our empire rows.
- Cliopatria time-slice features from `data/cliopatria-expanded-boundaries.geojson` (CC BY 4.0).
- Historical-basemap snapshot anchors from `data/historical-basemaps/geojson/` (GPL-3.0).
- Local prototype boundaries from `data/empire-boundaries-30.geojson`.
- AtlasPI GeoJSON export features where names match our empire rows. AtlasPI core is Apache-2.0; imported upstream datasets retain their original licenses. Source: https://github.com/Soil911/AtlasPI

The continuous layer is intended to show sourced coordinate snapshots for casual browsing. It is not a legal boundary dataset, and visual-atlas snapshots should not be cited as scholarly historical GIS evidence without checking their original sources.
